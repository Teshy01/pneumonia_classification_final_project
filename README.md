# pneumonia_classification_final_project
Final Project Submission for Group 3

How to run:
Please use the following link to download the dataset:
https://www.kaggle.com/datasets/kostasdiamantaras/chest-xrays-bacterial-viral-pneumonia-normal

Unzip and place the archive folder in the same directory as the jupyter notebooks. 

In order to run our code, please run the files in the following order:
  1. resnet_model_pneumonia_classification.ipynb
  2. PneumoniaClassificationDenseNet.ipynb
  3. deit_solution_model.ipynb

This should ensure that all the files run precisely and properly with no errors


## NOTE
The solution_model_troublshoot.pdf file contains the most up-to-date results for the DeiT base distilled solution model.
